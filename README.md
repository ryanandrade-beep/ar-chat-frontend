# A&R Chat — Frontend

Painel web do A&R Chat, plataforma para empresas gerenciarem o atendimento pelo WhatsApp e dispararem campanhas de marketing.

Feito com React, TypeScript e Vite. A API fica no repositório [ar-chat](https://github.com/ryanandrade-beep/ar-chat).

## Como executar

```bash
npm install
npm run dev      # http://localhost:5173
```
